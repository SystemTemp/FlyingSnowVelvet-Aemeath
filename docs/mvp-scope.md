# 范围与达成状态

## v0.1.0 已达成（可运行、可安装、可测试）

用户可见验收：

1. ✅ 双击 `AemeathPet.exe` 出现桌宠窗口（透明背景、无边框、置顶、不抢焦点）
2. ✅ 左键拖动移动，退出时保存位置；下次启动回到原位
3. ✅ 右键菜单 / 托盘菜单：聊天、设置、点击穿透、窗口置顶、重载动画、打开数据目录、退出
4. ✅ 帧动画循环播放（idle / talk / drag / wave），闲时随机切换动作
5. ✅ 聊天窗口可输入，`Enter` 发送；回复流式显示，后台线程不卡 UI
6. ✅ 聊天时可切换到 talk 动画，约 4 秒后回到 idle
7. ✅ 设置窗口可改置顶/穿透/缩放/AI 来源/endpoint/模型/人格/TTS 开关并持久化
8. ✅ 配置文件不存在时用默认值；存在时读取用户配置
9. ✅ 单实例：重复启动会提示已在运行
10. ✅ 日志写入 `%LOCALAPPDATA%\AemeathDeskPet\logs\aemeath.log`
11. ✅ 39 个自动化用例全绿；CI 在 Windows 上构建并运行测试
12. ✅ 在线安装器可从 Release 安装（含 SHA-256 校验）或用 `-FromSource` 从源码构建安装

## 下一阶段（按优先级）

### P1 系统集成补完

- 更新检查（GitHub Release API + SHA-256 校验 + 下载替换）
- 开机自启（注册表 Run 项或计划任务）
- 崩溃转储（MiniDumpWriteDump）与日志滚动
- 原生 C 安装器替换 PowerShell 脚本（进度 UI、卸载项、LZMA2 分片）

### P2 语音

- Windows SAPI TTS 接入（口型/时长回调 → talk 动画同步）
- SAPI 语音识别 + Push-to-Talk 热键
- 语音包安装（ONNX + UnRAR）与本地推理移植

### P2 音乐

- 本地播放（MCI / Media Foundation）
- QQ / 网易云 / 酷狗 provider（HTTP + 加密参数）
- 歌单面板、进度、音量、历史

### P3 渲染与表现

- 图层系统（多窗口叠加、z 序、命中测试）
- 粒子系统（首批：雪花、点击、爆裂）
- 世界对象（音响、雪球、雪堆）
- 托管原版 `native/dx_backend` 命令流后端

### P3 AI 车道

- 快捷福利池（清单缓存、模型轮换、冷却）
- 备用福利双源取密钥
- 图片输入 / 多模态模型优先
- 工具调用与命令分发

### P4 社区与扩展

- 论坛 UI（板块、编辑器、详情、Markdown、贴图）
- 办公 DSH 侧车
- 游戏包格式与运行器

## 不在范围内

- 社区管理/审核接口（客户端只做普通用户功能）
- 音乐平台账号体系的非官方登录态托管
- 任何绕过平台规则的能力
