# MVP 范围

## 用户可见验收标准

1. 双击启动后出现桌宠窗口。
2. 桌宠窗口无边框、透明背景、置顶。
3. 鼠标可拖动桌宠，位置可保存。
4. 右键菜单可打开聊天、设置、退出。
5. 聊天窗口可输入文本，Mock 服务返回回复。
6. 回复时桌宠进入 Talking 状态，随后回到 Idle。
7. 设置窗口可调整置顶、缩放、点击穿透等基础选项。
8. 配置文件不存在时加载默认值，存在时读取用户配置。
9. 应用退出时保存设置并清理后台任务。

## 非 MVP

- 真实大模型 API
- 流式回复
- 语音识别
- 语音合成
- 在线音乐
- 自动更新
- 插件、粒子、小游戏
- 办公侧车服务

## 推荐实现顺序

1. 创建 WinUI 3 C++ 项目。
2. 接入 `AemeathPet.Core` 静态库。
3. 启动 `MainWindow`。
4. 创建 `PetWindow` 并显示静态图片。
5. 加入 Win32 互操作：无边框、透明、置顶。
6. 实现拖拽与右键菜单。
7. 实现事件总线与 `PetState`。
8. 实现 `ChatWindow` + Mock 回复。
9. 实现 `SettingsWindow` + JSON 配置。
10. 补托盘和日志。
